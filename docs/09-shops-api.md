# WIZANO | وزانو — المحلات والانتماء (API)

| البند | القيمة |
|---|---|
| رقم الوثيقة | WZ-SHOP-001 |
| الإصدار | 1.0 |
| المرحلة | المرحلة 5 — المحلات والانتماء |
| المصدر | `server/src/modules/shops/` |

---

## 1. المفهوم

- **المحل** هو وحدة العزل المالي؛ كل البيانات المالية تُقيَّد بـ `shop_id`.
- عند إنشاء محل، يصبح المُنشئ **مالكًا (`owner`)** تلقائيًا، وتُهيَّأ له **عدّادات** أرقام العمليات لكل نوع (purchase/payment/return/adjustment).
- الانتماء يُخزَّن في `shop_members` (دور + مفاتيح صلاحيات للموظف). تعديل المحل مقصور على المالك.

---

## 2. المسارات

| الطريقة | المسار | الحالة | الصلاحية | الوصف |
|---|---|---|---|---|
| POST | `/api/v1/shops` | 201 | مُصادَق | إنشاء محل (يصبح المنشئ مالكًا) |
| GET | `/api/v1/shops` | 200 | مُصادَق | محلات المستخدم مع دوره ومفاتيحه فيها |
| GET | `/api/v1/shops/:shopId` | 200 | عضو فعّال | تفاصيل محل |
| PATCH | `/api/v1/shops/:shopId` | 200 | **مالك فقط** | تعديل الاسم/العملة/المنطقة/تاريخ الافتتاح |

**الطلب (إنشاء):**

```jsonc
{ "name": "بقالة الوادي", "currency": "YER", "timezone": "Asia/Aden", "openingDate": "2026-01-01" }
```

- `currency` الافتراضي `YER` (ISO 4217، 3 أحرف).
- `timezone` الافتراضي `Asia/Aden`، وتُتحقق صحته فعليًا عبر `Intl`.
- `openingDate` اختياري بصيغة `YYYY-MM-DD`.

**الطلب (تعديل):** أي مجموعة فرعية من الحقول؛ يجب إرسال حقل واحد على الأقل. `openingDate` يقبل `null` للتفريغ.

**الاستجابة:**

```jsonc
{ "data": { "id": "uuid", "name": "...", "currency": "YER", "timezone": "Asia/Aden",
            "openingDate": "2026-01-01", "status": "active", "createdAt": "...", "updatedAt": "..." } }
// GET /shops (قائمة)
{ "data": { "items": [ { "...": "...", "role": "owner", "permissionKeys": [] } ] } }
```

---

## 3. قواعد الفرض

- كل مسار يتطلب `Authorization: Bearer <access>` (وسيط `authenticate`).
- `GET/PATCH /:shopId` يمرّان عبر `requireShopMembership` (عزل المحل — R-06): `shop_id` يُستخرج من العضوية المؤكَّدة لا من الطلب.
- `PATCH` إضافةً لذلك يتطلب `role === "owner"`؛ وإلا 403 «تعديل بيانات المحل متاح للمالك فقط.».
- عدم الانتماء ⇒ 403 برسالة موحّدة لا تكشف وجود المحل.

---

## 4. الأخطاء

| الحالة | الكود | متى |
|---|---|---|
| 400 | `BAD_REQUEST` | فشل تحقق (اسم قصير/عملة/منطقة زمنية/تاريخ) |
| 401 | `UNAUTHORIZED` | لا رمز مصادقة |
| 403 | `FORBIDDEN` | لا انتماء للمحل، أو غير المالك يحاول التعديل |
| 404 | `NOT_FOUND` | المحل غير موجود (بعد تأكيد الانتماء) |

## 5. خارج نطاق هذه المرحلة

- إدارة الموظفين ومفاتيح صلاحياتهم عبر API (تُبنى مع أدوار الموظفين لاحقًا / حسب الحاجة).
- نقل ملكية المحل أو حذفه/إغلاقه.
- ربط العميل بالمحل (المرحلة 7).

# قائمة إطلاق WIZANO للإنتاج

لا تنشر إصدارًا عامًا حتى تُنجز كل عناصر «إلزامي».

## إلزامي قبل فتح التسجيل العام

- [ ] استبدال قاعدة Render المجانية بخطة إنتاجية، أو مزود PostgreSQL مدفوع.
- [ ] تنفيذ نسخة احتياطية يومية خارج مزود الاستضافة، ونجاح استرجاع تجريبي مرة واحدة على الأقل.
- [ ] وضع `DATABASE_URL` و`JWT_ACCESS_SECRET` و`CORS_ORIGINS` في متغيرات الاستضافة فقط، لا في GitHub.
- [ ] نطاق HTTPS خاص للخادم، مثل `api.wizano.app`.
- [ ] نشر سياسة الخصوصية من `privacy-policy-template.md` بعد استبدال كل الأقواس `[ ... ]` ببيانات صحيحة.
- [ ] إضافة رابط سياسة الخصوصية داخل التطبيق وفي Google Play.
- [ ] تحديد سياسة حذف الحساب: حذف كامل أم إخفاء/إبقاء قيود محاسبية وفق الاستشارة القانونية.
- [ ] إنشاء حساب مراجعة Google Play وتعليمات واضحة لتجربة صاحب المحل والعميل.
- [ ] بناء AAB موقّع، وليس APK فقط، ورفع نسخة Internal testing أولاً.
- [ ] مراجعة `targetSdk` عند البناء: تطبيقات Google Play الجديدة بعد 31 أغسطس 2026 تحتاج API 36 أو أعلى.

## فحص قبول على هاتفين حقيقيين

- [ ] إنشاء محل وعميل ودعوة العميل.
- [ ] شراء، دفعة، إلغاء/تصحيح، ثم مطابقة الرصيد في التطبيقين.
- [ ] إيقاف الإنترنت، تسجيل عملية ورسالة، ثم عودة الإنترنت والتأكد من مزامنتها مرة واحدة فقط.
- [ ] تحديث التطبيق فوق النسخة السابقة دون فقد المحل أو العملاء.
- [ ] إغلاق التطبيق بالقوة ثم فتحه دون اتصال؛ تظهر آخر البيانات بلا مطالبة بإعادة التسجيل.
- [ ] إرسال صوت قصير، تشغيله على الهاتف الآخر، وحذف الرسائل التجريبية.
- [ ] اختبار حسابين ومحلين للتأكد من عدم ظهور بيانات محل في الآخر.

## النسخ الاحتياطي

يعتمد السكربت `scripts/backup-postgres.ps1` على `pg_dump`:

```powershell
./scripts/backup-postgres.ps1 -DatabaseUrl "postgresql://..." -BackupDirectory "D:\WizanoBackups" -KeepDays 30
```

شغّله يوميًا من Windows Task Scheduler، ثم انقل النسخ إلى تخزين منفصل ومشفر. لا تضع رابط قاعدة البيانات أو النسخ الاحتياطية في GitHub.

## لا تعتبر هذه العناصر منجزة بعد

- إشعارات push حقيقية عبر Firebase؛ التحديث الحالي داخل التطبيق فقط.
- نقل الملفات الصوتية من Base64 في قاعدة البيانات إلى تخزين ملفات إنتاجي.
- استعادة كلمة المرور وتأكيد البريد/الهاتف.
- مراقبة الأخطاء والتنبيه عند توقف الخادم أو فشل النسخ الاحتياطي.

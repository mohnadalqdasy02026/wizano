## قرار التقنيات (معتمد في المرحلة 1)

- تطبيق صاحب المحل: Flutter 3.35.3 + Provider + sqflite
- تطبيق العميل: Flutter خفيف (مشروع مستقل)
- الخادم: Node.js 24 + Fastify + TypeScript + Drizzle ORM
- قاعدة البيانات: PostgreSQL 16.15
- العملة الافتراضية: ريال يمني (YER)

# WIZANO | وزانو — المدفوعات (API)

| البند | القيمة |
|---|---|
| رقم الوثيقة | WZ-PAY-001 |
| الإصدار | 1.0 |
| المرحلة | المرحلة 9 — المدفوعات |
| المصدر | `server/src/modules/payments/` |

---

## 1. المفهوم

- **الدفعة** (`payments`) قيد مالي مستقل يخصم من رصيد العميل: إمّا **دفعة عامة** على الحساب،
  أو **مرتبطة بعملية شراء** محددة (`purchaseId`).
- **العميل إلزامي** ويجب أن يكون مرتبطًا فعليًا بالمحل (عزل R-06).
- **الرصيد** لا يُعدَّل يدويًا؛ يُحسب من السجلات المالية (D-09):
  `رصيد العميل = Σ المشتريات (النشطة) − Σ المدفوعات`، ويُخزَّن «الرصيد بعد الدفعة» (`balance_after`).
- **رقم الدفعة** (`shop_seq`) فريد ضمن المحل عبر عدّادات `shop_counters` (kind = payment).
- ملاحظة: الدفعة الناتجة عن «المبلغ المدفوع وقت الشراء» تُنشأ تلقائيًا في وحدة المشتريات (المرحلة 8)؛
  هذه الوحدة تسجّل الدفعات **المستقلة** الإضافية.

---

## 2. المسارات

كل المسارات تحتاج `Authorization: Bearer <access>` + انتماء فعّال للمحل (`requireShopMembership`).

| الطريقة | المسار | الحالة | الوصف |
|---|---|---|---|
| GET | `/api/v1/shops/:shopId/payments?customerId=` | 200 | قائمة دفعات المحل (اختياريًا لعميل) |
| POST | `/api/v1/shops/:shopId/payments` | 201 | تسجيل دفعة (عامة أو مرتبطة بعملية) |
| GET | `/api/v1/shops/:shopId/payments/:paymentId` | 200 | تفاصيل دفعة |

**الطلب (إنشاء):**

```jsonc
{
  "id": "uuid-v7-اختياري",   // معرّف ثابت من التطبيق (D-07) — يمنع التكرار
  "customerId": "uuid",      // إلزامي، عميل مرتبط بالمحل
  "purchaseId": "uuid",      // اختياري: ربط الدفعة بعملية شراء محددة
  "amount": 1500,            // إلزامي، > 0
  "notes": "...",            // اختياري
  "paidAt": "2026-10-20T22:28:00.000Z" // اختياري (افتراضي: الآن)
}
```

- الترويسة `Idempotency-Key` اختيارية: عند إعادة الإرسال بنفس المفتاح تُعاد الدفعة القائمة (R-07).

**الاستجابة (دفعة):**

```jsonc
{ "data": {
  "id": "uuid", "shopId": "uuid", "customerId": "uuid",
  "purchaseId": null, "amount": "1500", "paidAt": "...",
  "shopSeq": "3", "notes": null, "balanceAfter": "8500",
  "createdAt": "...", "updatedAt": "..." } }
// القائمة
{ "data": { "items": [ { "...": "..." } ] } }
```

> **ملاحظة:** المبالغ تُعاد كسلاسل نصية (bigint) لتجنّب فقدان الدقة في JavaScript.

## 3. قواعد

- **العزل:** عدم الانتماء للمحل ⇒ 403؛ عميل غير مرتبط ⇒ 404 (لا نكشف وجوده).
- **المبلغ:** `amount > 0` (يُفرض على المدخلات وعلى القاعدة عبر CHECK).
- **دفعة مرتبطة بعملية:** يجب أن تكون العملية لنفس المحل **ونفس العميل** (وإلا 404)،
  وألا يتجاوز المبلغ **متبقي تلك العملية** (إجمالي العملية − ما دُفع عليها) وإلا 400.
- **دفعة عامة:** لا تجعل رصيد العميل سالبًا؛ منع «الدفعة المقدمة الزائدة» (§4.1) وإلا 400
  برسالة: «المبلغ يتجاوز إجمالي المتبقي على العميل.».
- **منع التكرار:** نفس `id` من العميل ⇒ تُعاد الدفعة القائمة؛
  نفس `Idempotency-Key` ⇒ تُعاد الدفعة القائمة (مع تسجيل في `sync_operations`).
- **العدّاد:** `shop_counters(kind = payment)` يُزاد ذرّيًا داخل المعاملة.

---

## 4. الأخطاء

| الحالة | الكود | متى |
|---|---|---|
| 400 | `BAD_REQUEST` | فشل التحقق (مبلغ ≤ 0، تجاوز متبقي العملية/الرصيد) |
| 401 | `UNAUTHORIZED` | لا رمز مصادقة |
| 403 | `FORBIDDEN` | لا انتماء للمحل |
| 404 | `NOT_FOUND` | الدفعة/العملية غير موجودة، أو العميل غير مرتبط بالمحل |

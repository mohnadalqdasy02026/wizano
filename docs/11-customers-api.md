# WIZANO | وزانو — العملاء وربط العميل بالمحل (API)

| البند | القيمة |
|---|---|
| رقم الوثيقة | WZ-CUST-001 |
| الإصدار | 1.0 |
| المرحلة | المرحلة 7 — العملاء وربط العميل بالمحل |
| المصدر | `server/src/modules/customers/` |

---

## 1. المفهوم

- **العميل** كيان عالمي (`customers`) ببيانات غير مالية فقط (اسم، هاتف، ملاحظات).
- كل وصول للعميل يمرّ عبر **رابط العميل بالمحل** (`customer_shop_links` بحالة `active`)؛
  وهذا يحقق العزل (R-06): لا تظهر عملاء محل لمحل آخر ولا يمكن الوصول إليها.
- **الربط** يتم بطريقتين: (أ) إنشاء عميل داخل المحل ⇒ ربط داخلي تلقائي؛
  (ب) رمز دعوة (`invitations`) يُسلَّم للعميل ليربط حسابه بالمحل لاحقًا (تطبيق العميل، المراحل 17-19).

---

## 2. المسارات

كل المسارات تحتاج `Authorization: Bearer <access>` + انتماء فعّال للمحل (`requireShopMembership`).

| الطريقة | المسار | الحالة | الوصف |
|---|---|---|---|
| GET | `/api/v1/shops/:shopId/customers?search=` | 200 | قائمة عملاء المحل (+ بحث بالاسم/الهاتف) |
| POST | `/api/v1/shops/:shopId/customers` | 201 | إنشاء عميل وربطه بالمحل |
| GET | `/api/v1/shops/:shopId/customers/:customerId` | 200 | تفاصيل عميل |
| PATCH | `/api/v1/shops/:shopId/customers/:customerId` | 200 | تعديل بيانات غير مالية |
| DELETE | `/api/v1/shops/:shopId/customers/:customerId` | 204 | أرشفة (حذف منطقي) |
| POST | `/api/v1/shops/:shopId/customers/:customerId/invitations` | 201 | إنشاء رمز دعوة لربط العميل |

**الطلب (إنشاء):**

```jsonc
{ "displayName": "أحمد السامعي", "phone": "777123456", "notes": "..." }
```

- حقل `id` اختياري (UUIDv7 من التطبيق لأجل المزامنة/عدم الاتصال)؛ يُولَّد خادميًا إن غاب.
- `displayName` حد أدنى حرفان؛ `phone` اختياري؛ `notes` اختياري.

**الاستجابة (عميل):**

```jsonc
{ "data": { "id": "uuid", "displayName": "...", "phone": "...", "notes": "...",
            "archivedAt": null, "createdAt": "...", "updatedAt": "..." } }
// القائمة
{ "data": { "items": [ { "...": "..." } ] } }
// رمز الدعوة
{ "data": { "id": "uuid", "code": "AB23CD45", "status": "pending", "expiresAt": "..." } }
```

---

## 3. قواعد

- **العزل:** عدم الانتماء للمحل ⇒ 403 (رسالة موحّدة لا تكشف وجود المحل).
- عميل غير مرتبط بالمحل ⇒ 404 (لا نكشف وجوده).
- **البحث:** `ILIKE` على الاسم والهاتف.
- **الأرشفة:** ضبط `archived_at`؛ يختفي من القائمة دون حذف العمليات المالية المرتبطة.
- **رمز الدعوة:** 8 أحرف من مجموعة بلا أحرف ملتبسة، فريد، صلاحية 7 أيام، الحالة `pending`.
  الاستهلاك من تطبيق العميل في مرحلة لاحقة.
- **نسخة العميل (`version`):** تُزاد عند كل تعديل (قفل تفاؤلي لتعارضات المزامنة).

---

## 4. الأخطاء

| الحالة | الكود | متى |
|---|---|---|
| 400 | `BAD_REQUEST` | فشل تحقق المدخلات |
| 401 | `UNAUTHORIZED` | لا رمز مصادقة |
| 403 | `FORBIDDEN` | لا انتماء للمحل |
| 404 | `NOT_FOUND` | العميل غير موجود أو غير مرتبط بالمحل |

---

## 5. خارج نطاق هذه المرحلة

- الرصيد المحسوب للعميل (الوحدات المالية، المراحل 8+).
- استهلاك رمز الدعوة من تطبيق العميل (المراحل 17-19).
- التمثيل المالي للعميل في كشف الحساب (المرحلة 10).
